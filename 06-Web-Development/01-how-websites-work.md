# Lesson 1 - How Websites Work

A browser requests resources from a server and then builds and displays the page.

A simplified flow is:

```
Browser -> Request -> Server
Browser <- HTML/CSS/JS <- Server
Browser -> Builds page -> User sees website
```

HTML provides structure, CSS presentation, and JavaScript behavior.

## Practice
Open a website's developer tools and identify an HTML element, a CSS rule, and a JavaScript file.
