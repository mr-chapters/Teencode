# Lesson 3 - Conditions and Loops

Conditions let programs make decisions.

```js
const score = 80;
if (score >= 50) {
  console.log("Pass");
} else {
  console.log("Try again");
}
```

Loops repeat work.

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```
