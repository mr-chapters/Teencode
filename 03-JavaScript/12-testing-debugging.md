# JavaScript Testing and Debugging

Professional developers do not assume code works because it ran once.

## Browser developer tools

The browser console can show errors and values.

You can also use:

```javascript
console.log(value);
```

to inspect what your program is doing.

## Breakpoints

A debugger can pause execution so you can inspect variables step by step.

The exact interface depends on the browser, but the idea is the same: stop the program at an important line and inspect its state.

## Testing cases

For a function that calculates a percentage, test:
- normal values
- zero
- maximum values
- invalid values
- unexpected types when relevant

## Practice

Write a function and deliberately give it a wrong input. Use the console and debugger to discover what happened.
