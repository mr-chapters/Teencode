# Lesson 2 - Variables, Types, and Operators

Variables store values.

```js
const name = "Alex";
let score = 10;
score = score + 5;
```

Common values include strings, numbers, booleans, arrays, objects, `null`, and `undefined`.

Use `const` when a variable is not reassigned and `let` when it changes.
