# JavaScript Basics

JavaScript is a programming language. HTML describes structure, CSS describes presentation, and JavaScript can control behavior.

## 1. Running JavaScript

In a browser, you can use the developer console:

```javascript
console.log("Hello, TeenCode!");
```

You can also connect JavaScript to an HTML page:

```html
<script src="script.js"></script>
```

## 2. Statements

A statement is an instruction in your program.

```javascript
console.log("Hello");
console.log(2 + 3);
```

JavaScript executes these instructions in order unless another control structure changes the flow.

## 3. Expressions

An expression produces a value.

```javascript
2 + 3
"Hello" + " world"
10 > 5
```

Understanding the difference between instructions and values helps when you start writing larger programs.

## 4. Comments

```javascript
// This is a comment
console.log("This runs");
```

Use comments to explain decisions or important details, not to repeat obvious code.
