# Specializations

After the core curriculum, choose a direction and go deeper.

## Paths

- [Frontend Development](frontend.md)
- [Backend Development](backend.md)
- [Game Development](games.md)
- [Mobile and Applications](applications.md)
- [Data and Automation](data.md)

You do not need to learn every path. Choose one that matches the kind of software you want to build.

## How to Choose

Look at projects you enjoy. If you like interfaces, explore frontend. If you like servers and data, explore backend. If you like interactive worlds, explore games.

Keep building projects while you specialize.
