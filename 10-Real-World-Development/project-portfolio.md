# Portfolio Project

Build and document one project you are proud to show.

## Requirements
- clear problem statement
- working software
- organized repository
- README
- screenshots or demo when appropriate
- testing notes
- known limitations
- explanation of what you learned

## Final Review
Ask yourself:
- Can another person understand this project?
- Can they run it?
- Did I test important behavior?
- Did I explain what I would improve next?

This completes the main TeenCode curriculum.
