# Contributing to TeenCode

TeenCode is designed to be beginner-friendly and easy for students to follow.

## Ways to Contribute

You can contribute by:

- Improving explanations
- Fixing mistakes
- Adding examples
- Creating exercises
- Adding beginner-friendly projects
- Improving documentation

## Guidelines

- Keep explanations clear and beginner-friendly.
- Explain why code works, not only what to type.
- Avoid unnecessary complexity in beginner lessons.
- Keep lessons organized inside the correct folder.
- Do not use emojis or stickers in lesson content.
- Test code examples before submitting them.

More detailed contribution rules will be added as the curriculum grows.
