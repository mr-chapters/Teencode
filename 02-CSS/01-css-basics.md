# Lesson 1 - CSS Basics

CSS changes how HTML content is displayed.

You can connect a stylesheet with:

```html
<link rel="stylesheet" href="style.css">
```

Then write:

```css
body {
  font-family: Arial, sans-serif;
}

h1 {
  font-size: 2rem;
}
```

A CSS rule has a selector and declarations.

## Practice

Style a page by changing its font, heading size, paragraph spacing, and page width.

## Key Idea

Keep structure in HTML and presentation rules in CSS whenever practical.
