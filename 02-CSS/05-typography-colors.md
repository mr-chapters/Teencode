# CSS Typography and Color

Good visual design begins with readable content.

## Font properties

```css
body {
  font-family: Arial, sans-serif;
  line-height: 1.6;
}

h1 {
  font-size: 2rem;
  font-weight: 700;
}
```

Line height controls the vertical space between lines.

## Color

CSS supports several color formats.

```css
.title {
  color: #222222;
  background: white;
}
```

Do not choose colors only because they look nice. Text must remain readable.

## Units

Common units include:
- `px` for fixed pixels
- `rem` for sizes relative to the root font size
- `%` for relative sizing
- `vw` and `vh` for viewport dimensions
