# CSS Project - Style Your Personal Site

Take the HTML project and turn it into a polished responsive webpage.

## Requirements

Use:

- an external stylesheet
- reusable classes
- the box model
- Flexbox or Grid
- spacing
- typography
- a responsive media query
- visible hover states for links or buttons

Do not solve everything with inline styles.

## Challenge

Create a consistent design system using a small set of spacing and typography choices.
