# TeenCode Roadmap

This roadmap is the learning path for TeenCode.

The goal is not to rush through programming languages. The goal is to understand the fundamentals, practice them, and eventually use them to build real software.

Students should move through the roadmap in order when possible. Some topics can be revisited later as projects become more advanced.

---

## Stage 0 - [Getting Started](00-Getting-Started/README.md)

Before writing serious code, students should understand what programming is and how developers work.

### Topics

- What programming is
- What a programming language is
- How computers execute instructions
- Source code and programs
- Files and folders
- Code editors
- Terminals and command lines
- Installing development tools
- How websites, applications, and games are made
- What bugs are
- How programmers debug problems
- Basic internet and web concepts
- How to read documentation
- How to ask good programming questions

### Goal

Students should be comfortable opening a project, creating files, running simple programs, and understanding basic programming vocabulary.

### First Projects

- A personal introduction page
- A simple calculator
- A program that prints information about the student

# Project Progression

Projects should become harder as students improve.

## Beginner

Projects should focus on one or two major concepts.

Examples:

- Calculator
- Quiz
- Personal webpage
- Number guessing game
- To-do list

## Intermediate

Projects should combine several technologies.

Examples:

- Weather application
- Notes application
- Blog
- API-based dashboard
- Small game

## Advanced

Projects should require planning, architecture, debugging, testing, and documentation.

Examples:

- Full-stack application
- Multiplayer-style game
- Learning platform
- School management system
- Large portfolio project

# How To Know You Are Ready To Move On

Do not move to the next stage simply because you finished reading the lessons.

A student should be able to:

- Explain the main concepts in their own words.
- Write small programs without copying every line.
- Debug common mistakes.
- Read unfamiliar code.
- Modify an existing project.
- Build a small project using the concepts learned.
- Explain why their code works.

If a topic is difficult, go back and practice it.

Programming is cumulative. Strong fundamentals make advanced topics much easier.

---

# TeenCode Learning Rule

The basic cycle for every topic is:

Learn -> Understand -> Practice -> Build -> Debug -> Improve

Reading tutorials is only one part of learning programming.

The most important part is building.

---

# Roadmap Completion

Completing the roadmap does not mean a student has learned all of programming.

Programming is a large field and technologies change.

Completing TeenCode means a student should have:

- Strong programming fundamentals
- Experience with multiple languages
- Experience building websites
- Experience building applications
- Experience building games
- Experience using Git and GitHub
- Experience working with APIs
- Basic database knowledge
- Basic software engineering knowledge
- A collection of real projects
- The ability to continue learning independently

The final goal is not to memorize code.

The final goal is to become capable of learning, building, debugging, and solving problems independently.
