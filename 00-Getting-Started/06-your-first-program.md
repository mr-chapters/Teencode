# Lesson 6 - Your First Program

## Learning Goal

Write and run a small Python program.

## Your First Program

Create a file called:

```
first_program.py
```

Write:

```python
print("Hello, TeenCode!")
```

When you run the program, it displays:

```
Hello, TeenCode!
```

## What Does print() Do?

`print()` tells Python to display a value.

For example:

```python
print("I am learning programming.")
print("I want to build useful projects.")
```

Each statement displays text.

## Variables

A variable gives a value a name.

```python
name = "Your Name"
print("Hello, " + name)
```

If the variable contains `Alex`, the program displays:

```
Hello, Alex
```

## Experiment

Write a program that prints:

1. Your name.
2. Something you want to learn.
3. Something you want to build.

For example:

```python
print("My name is Alex.")
print("I am learning Python.")
print("I want to build a game.")
```

## Challenge

Use variables instead:

```python
name = "Your Name"
learning = "Python"
building = "a game"

print(name)
print(learning)
print(building)
```

Change the values and run the program again.

## Key Idea

You have now written a real program. It may be tiny, but the process is the same basic cycle you will use for much larger projects: write code, run it, observe the result, and improve it.
