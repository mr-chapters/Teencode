# Lesson 5 - The Terminal and Command Line

## Learning Goal

Understand what a terminal is and why programmers use it.

## What Is a Terminal?

A terminal is a text-based way to interact with your computer.

Instead of clicking buttons and folders, you can type commands.

The program that interprets those commands is commonly called a shell.

## Common Commands

On macOS and Linux, a common command for listing files is:

```bash
ls
```

On Windows Command Prompt, a common equivalent is:

```text
dir
```

To move into a folder, you can use:

```bash
cd folder-name
```

The exact commands can vary between shells and operating systems.

## Why Programmers Use the Terminal

The terminal is useful for tasks such as:

- running programs
- installing packages
- working with Git
- starting development servers
- running tests
- automating tasks
- working with remote computers

You will use it more as you progress through TeenCode.

## Important Rule

Do not run a command just because someone told you to copy and paste it.

Understand what the command is supposed to do before running it, especially commands that can delete or modify files.

## Practice

Without worrying about memorizing commands, identify:

1. The command you would use on Linux or macOS to list files.
2. A Windows Command Prompt command that lists files.
3. The command pattern used to move into a folder.

## Key Idea

The terminal gives you another way to control your computer. You do not need to memorize every command. Learn what commands mean and when to use them.
