# Lesson 9 - How to Read Documentation

## Learning Goal

Learn why programmers use documentation and how to get useful information from it.

## What Is Documentation?

Documentation is information that explains how software, programming languages, libraries, tools, or systems work.

Documentation can include:

- explanations
- tutorials
- examples
- function descriptions
- parameters
- return values
- configuration instructions
- warnings
- troubleshooting information
- reference pages

## Why Documentation Matters

You will not remember everything.

Even experienced programmers regularly look things up.

Good programmers learn how to find reliable information and understand what they find.

## How to Read a Reference Page

When you find documentation for a function or feature, look for:

1. What does it do?
2. What information does it need?
3. What does it return or produce?
4. Are there examples?
5. Are there important limitations or errors?

## Example: Python str()

Suppose you need to convert a number into text.

You might look up Python's `str()` function.

You want to find out:

- what `str()` does
- what you can pass to it
- what it returns
- how it is used

Then you can apply the information to your own code.

## Practice

Look up the Python documentation for `str()`.

Before reading the example, try to predict what this does:

```python
age = 15
message = str(age)
print(message)
```

Then check the documentation and compare your prediction.

## Key Idea

Programming is not about memorizing everything. It is about understanding concepts and knowing how to find trustworthy information when you need it.
