# Getting Started

Welcome to the beginning of TeenCode.

This section is for students who are completely new to programming. You do not need previous coding experience.

The goal is to understand what programming is, set up your tools, learn how programmers think, and write your first small programs.

## Lessons

1. [What Is Programming?](01-what-is-programming.md)
2. [How Computers Run Code](02-how-computers-run-code.md)
3. [Files, Folders, and Projects](03-files-folders-and-projects.md)
4. [Code Editors](04-code-editors.md)
5. [The Terminal and Command Line](05-terminal-and-command-line.md)
6. [Your First Program](06-your-first-program.md)
7. [What Is a Bug?](07-what-is-a-bug.md)
8. [How to Debug](08-how-to-debug.md)
9. [How to Read Documentation](09-reading-documentation.md)
10. [How to Ask Good Programming Questions](10-asking-good-questions.md)

## Final Challenge

After completing the lessons, complete the [Getting Started Project](project-01-first-program.md).

You should be able to explain basic programming vocabulary, create a project, run a program, identify simple errors, and explain how you found a solution.
