# Lesson 3 - Files, Folders, and Projects

## Learning Goal

Learn how programmers organize code and other project files.

## Files

A file stores information.

Examples include:

- `index.html`
- `style.css`
- `script.js`
- `main.py`
- `README.md`

The file extension often gives you a clue about what kind of file it is.

## Folders

A folder is used to organize files and other folders.

A small website might look like this:

```
my-project/
├── index.html
├── style.css
└── script.js
```

A larger application might look like this:

```
my-app/
├── src/
├── assets/
├── tests/
├── README.md
└── package.json
```

The exact structure depends on the project.

## What Is a Project?

A project is a collection of files and resources that work together to create something.

A project could be:

- a website
- a game
- a mobile application
- a Python program
- a school assignment
- a tool or automation script

Good organization becomes more important as projects get larger.

## File Paths

A file path tells you where a file is located.

For example:

```
my-project/index.html
```

means that `index.html` is inside the `my-project` folder.

## Why Organization Matters

Imagine having 300 files in one folder with random names. Finding the file you need would be difficult.

Organized projects make it easier to:

- find files
- understand a project
- work with other people
- fix problems
- add new features

## Practice

Create a folder called:

```
my-first-project
```

Inside it, create a file called:

```
notes.txt
```

Write three things you want to learn about programming.

## Challenge

Design a folder structure for a personal website.

Decide where you would put:

- HTML files
- CSS files
- JavaScript files
- images
- project notes

You do not need to create it yet. Draw the structure first.

## Key Idea

Good programmers do not only write code. They organize their projects so the code and other files are easy to understand and maintain.
