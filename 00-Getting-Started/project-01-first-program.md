# Getting Started Project - Your First Program

## Goal

Build a small Python program that introduces the user and asks what they want to learn and build.

This project brings together the basic ideas from the Getting Started lessons.

## Requirements

Your program should:

1. Ask the user's name.
2. Ask what they want to learn.
3. Ask what they want to build.
4. Display the information back to the user.

## Example Solution

```python
name = input("What is your name? ")
learning = input("What do you want to learn? ")
building = input("What do you want to build? ")

print("Hello, " + name)
print("You want to learn " + learning)
print("You want to build " + building)
```

Do not just copy the example and stop. Read each line and make sure you understand what it does.

## Extra Challenge

Add two more questions.

For example:

- What programming language interests you?
- What kind of project would you like to make first?

Store the answers in variables and display them.

## Completion Checklist

Before moving on, make sure you can:

- Create a Python file.
- Run a Python program.
- Explain what `print()` does.
- Explain what `input()` does.
- Explain what a variable is.
- Recognize a basic error.
- Read an error message.
- Make a small change and test the result.
- Explain one problem you solved while completing the project.
