# Lesson 4 - Code Editors

## Learning Goal

Understand what a code editor is and learn the features that make programming easier.

## What Is a Code Editor?

A code editor is a program designed for writing and working with text, especially source code.

Common examples include:

- Visual Studio Code
- Sublime Text
- Notepad++
- Vim
- Neovim

You do not need to use the same editor as another programmer. Choose one that works well for you.

## Useful Features

Modern code editors often provide:

### Syntax Highlighting

Different parts of code can be displayed differently so the structure is easier to read.

### Autocomplete

The editor can suggest names, keywords, and other pieces of code.

### Search

You can find text across a file or, in many editors, across an entire project.

### Find and Replace

You can change repeated text quickly.

### Extensions

Some editors allow additional tools for languages, formatting, debugging, Git, and other tasks.

### File Navigation

A project sidebar can help you move between folders and files.

### Integrated Terminal

Some editors include a terminal so you can run commands without leaving the editor.

## Your First Editor Exercise

Create a file called:

```
hello.py
```

Put this inside:

```python
print("Hello, TeenCode!")
```

Save the file.

You will learn how to run it in the next lessons.

## Practice

Open your code editor and identify:

1. Where files are displayed.
2. Where you type code.
3. Where you can search.
4. Whether your editor has a terminal.
5. How you save a file.

## Key Idea

A code editor is a tool. It helps you write code, but the important skill is understanding the code you are writing.
