# Lesson 1 - What Is Programming?

## Learning Goal

By the end of this lesson, you should understand what programming is, what code is, and why we use programming languages.

## What Is Programming?

Programming is the process of giving a computer precise instructions to solve a problem or perform a task.

A computer does not normally guess what you mean. Your instructions need to be specific enough for the computer to follow.

For example, a simple Python program can add two numbers:

```python
price1 = 10
price2 = 5
total = price1 + price2

print(total)
```

The program stores two numbers, adds them, stores the result, and displays it.

## What Is Code?

Code is the set of instructions written in a programming language.

Think of code as a set of instructions for a computer. The better you understand the problem, the easier it becomes to write useful code.

## What Is a Programming Language?

A programming language gives programmers rules and words for writing instructions.

Some languages you will meet in TeenCode include:

- Python
- JavaScript
- Java
- C#
- C++
- Go
- Rust

HTML and CSS are also essential web technologies, but they have different roles from general-purpose programming languages. HTML describes the structure of a webpage, while CSS controls its appearance.

## Why Are There So Many Languages?

Different languages are designed with different goals.

For example:

- Python is popular for beginners, automation, data work, and many other tasks.
- JavaScript is central to interactive websites and is also used outside browsers.
- C++ is used in areas such as games and performance-heavy software.
- Java and C# are widely used for large applications and other software.
- Go is designed for practical, efficient software and services.
- Rust focuses strongly on performance and memory safety.

You do not need to learn all of them at once.

TeenCode focuses on learning programming ideas first. Once you understand the ideas, learning another language becomes much easier.

## Programming Is Problem Solving

A programmer usually starts with a problem.

For example:

> I want a program that calculates the total price of two items.

Before writing code, you can break the problem into steps:

1. Get the first price.
2. Get the second price.
3. Add the prices.
4. Display the result.

Then you translate those steps into code.

That is one of the most important ideas in programming:

**Programming is not just typing code. It is solving problems and expressing the solution clearly.**

## Practice

Imagine you are writing instructions for someone who has never made a sandwich.

Write very clear steps for making one.

Notice how vague instructions can cause confusion. Programming works in a similar way: instructions need to be precise.

## Challenge

Describe, in plain English, the steps a computer would need to follow to add two numbers entered by a user.

Do not write code yet. Focus on the steps.
