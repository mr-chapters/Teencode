# HTML Project - Personal Page

Build a one-page personal website.

## Requirements

Include:

- a page title
- a main heading
- an introduction
- a list of interests
- one image with useful `alt` text
- two links
- a simple contact form
- semantic page structure

## Challenge

Create a second page called `about.html` and connect both pages with navigation.

## Completion

Make sure your HTML is readable, consistently indented, and uses elements for their intended meaning.
