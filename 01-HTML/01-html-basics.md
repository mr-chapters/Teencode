# Lesson 1 - HTML Basics

HTML describes the structure and meaning of content on a webpage.

A basic document looks like this:

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
</head>
<body>
  <h1>Hello</h1>
  <p>I am learning HTML.</p>
</body>
</html>
```

An HTML element normally has an opening tag, content, and a closing tag.

`<h1>` creates a main heading and `<p>` creates a paragraph.

The `head` contains information about the document. The `body` contains visible page content.

## Practice

Create `index.html` with a heading, two paragraphs, and a title.

## Key Idea

HTML is about structure and meaning, not visual styling.
