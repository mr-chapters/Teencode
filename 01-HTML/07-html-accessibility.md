# HTML Accessibility

Accessibility means designing websites so more people can use them.

## Semantic structure

Use headings in a logical order.

```html
<h1>My Study Website</h1>
<h2>Subjects</h2>
<h3>Mathematics</h3>
```

Do not choose a heading only because it looks large. Use it because it represents a section.

## Labels

Every form control should have a useful label.

## Buttons and links

Use a button for an action and a link for navigation.

Good:

```html
<button type="button">Start quiz</button>
<a href="lessons.html">Lessons</a>
```

Avoid replacing these with clickable `div` elements.

## Keyboard use

A user should be able to navigate important controls without relying only on a mouse.

## Practice

Take an old webpage and check:
- heading structure
- image alternative text
- form labels
- link names
- keyboard usability

## Challenge

Improve the accessibility of your personal-page project and document what you changed.
