# Lesson 2 - Text, Links, and Images

Use headings and paragraphs to organize text.

A link uses an anchor element:

```html
<a href="https://example.com">Visit the site</a>
```

An image can be added with:

```html
<img src="images/photo.jpg" alt="A description of the photo">
```

The `alt` attribute provides useful text when an image cannot be seen and helps accessibility.

Use relative paths for files inside your project.

## Practice

Build a page containing a heading, three paragraphs, one link, and one local image with useful alternative text.

## Challenge

Add links to two different pages in your project.
