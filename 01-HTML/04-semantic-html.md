# Lesson 4 - Semantic HTML

Semantic HTML uses elements according to their meaning.

Common elements include:

- `header` for introductory content
- `nav` for navigation
- `main` for the primary content
- `section` for a thematic section
- `article` for an independent piece of content
- `footer` for closing information

Compare a page made mostly from generic `div` elements with one that uses meaningful elements.

Semantic structure can make pages easier for people, search engines, and assistive technology to understand.

## Practice

Take a simple personal page and organize it with `header`, `nav`, `main`, `section`, and `footer`.

## Key Idea

Choose an HTML element because of what the content means, not because of how it looks.
