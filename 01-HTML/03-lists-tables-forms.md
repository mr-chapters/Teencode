# Lesson 3 - Lists, Tables, and Forms

Lists organize groups of information.

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

Ordered lists use `<ol>`.

Tables are useful for genuinely tabular information:

```html
<table>
  <tr><th>Language</th><th>Use</th></tr>
  <tr><td>Python</td><td>Programming</td></tr>
</table>
```

Forms collect user input:

```html
<form>
  <label for="name">Name</label>
  <input id="name" name="name" type="text">
  <button type="submit">Send</button>
</form>
```

Labels make forms easier to understand and use.
